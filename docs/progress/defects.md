# Defect log

Every defect found while building Earth-Hub, from Milestone 1 to Milestone 9. Each was fixed in the milestone where it was found, except the ones marked **open** (DEF-066 and DEF-067), which are still to work on, and covered by a regression test where a test could catch it. All but seven were found before their code was merged: DEF-034 and DEF-036 in the live logs, DEF-035 in the public dashboard, DEF-037 in a script already merged, DEF-038 and DEF-039 in an audit of the documents against the code, and DEF-053 in the backfill, while preparing a run.

Six were written up in full, as examples of the [defect report template](#template), because they show the most instructive failure modes. Those six are fixed, so the reports were removed from the working tree on 2026-10-20; they remain in the git history, and their IDs in the log link to them as of commit `b9102de`.

## Severity and priority

| Severity | Meaning |
| --- | --- |
| Critical | Data loss or corruption, or a security exposure, with no workaround |
| High | A core function fails, results become unreliable, or secrets could leak |
| Medium | A function misbehaves in specific conditions; a workaround exists |
| Low | Cosmetic, a standards deviation, or a minor inconvenience |

Priority is how urgently it had to be fixed: **P1** before anything else, **P2** within the milestone, **P3** when convenient. All 41 were fixed within their milestone, or in a follow-up straight after.

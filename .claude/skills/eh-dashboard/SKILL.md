# Dashboard

Run from the repository root. Live page: https://earth-hub.diego-narvaez.workers.dev (shared by link, kept out of
search engines).

| Argument | Command |
| --- | --- |
| `check` (default) | `curl -s -o /dev/null -w '%{http_code} %{time_total}s\n' $URL/`, `curl -s $URL/data/meta.json \| jq '{run_id, written_at, rows, bytes}'`, and `curl -sI $URL/data/earthquakes.parquet \| grep -iE '^(etag\|content-length\|cache-control\|x-robots-tag)'`, the live build `curl -s $URL/ \| grep -o 'id="source"[^>]*>[^<]*' \| sed 's/.*>//'`, and `curl -s -o /dev/null -w '%{http_code}\n' $URL/privacy` (200) |
| `dev` | `make dashboard-dev` in the background: builds, then serves http://127.0.0.1:8787 over the **real** bucket (read-only). Report the address when `Ready on` appears |
| `build` | `make dashboard-build` (writes `dashboard/dist`, with `third-party-licenses.txt`) |
| `test` | `make test-dashboard`: the page in Chromium against a simulated R2, offline (~3–6 min) |
| `deployments` | `cd dashboard && npx --no-install wrangler deployments list 2>&1 \| grep -v '@'` (needs `npx wrangler login` once) |
| `deploy` | `make dashboard-deploy` (the page, the Worker and its cron triggers, `5 */4 * * *` and `10 0 * * *`) |
| `trigger` | `make -s trigger-check 2>&1 \| grep -v '@' \| tail -1` (on Cloudflare, with the deployed token: `trigger check: OK … (N days left)`, or why not; starts nothing), `cd dashboard && npx --no-install wrangler secret list 2>&1 \| grep -v '@'` (`GITHUB_TOKEN` listed, never its value), `make -s direct-runs LIMIT=3` (the latest rounds, `cloudflare-trigger`), and `gh run list --workflow direct.yml --limit 5`. Its live log: `cd dashboard && npx --no-install wrangler tail earth-hub --format json` in the background over the next round, at :05 every 4 hours (`trigger: direct round started`, or GitHub's refusal) |

(In the table `\|` is a pipe; run it as `|`.)

- **Deploy only when the user's request says deploy.** It publishes to the public URL and the triggers. Afterwards
  run `check`, confirm `X-Robots-Tag: noindex, nofollow` is still served and the output says `schedule: 5 */4 * * *`
  and `schedule: 10 0 * * *`. If Wrangler warns that the remote configuration differs and shows a value under
  `vars` (a token set as a dashboard variable), that value is exposed: tell the user at once to revoke and rotate it
  (`make trigger-token`), and never repeat it.
- Wrangler's output can include the account's email: always filter lines with `@` before showing it.
- `dashboard/wrangler.jsonc` is generated by `scripts/dashboard_config.py`; never commit it.
- The page shows the last snapshot written to the bucket, never a deploy's: in full mode by `/eh-export run`,
  in direct mode by every direct round (every 4 hours on GitHub Actions, started by this Worker's cron trigger; `/eh-mode`).
- `dev` and `test` need `make dashboard-install` once.
- **The trigger's token** (`GITHUB_TOKEN`, a Worker secret) is the user's: `make trigger-token` in a terminal creates,
  checks and stores it as an encrypted secret, and replaces it before it expires (GitHub e-mails a failed `Trigger
  token` run from 14 days before). Never run it for them, never ask for or print the token, and never have it set as a
  variable in the Cloudflare dashboard. `make trigger-check` (safe to run) says whether the stored token works.
- **The footer and privacy** (docs/technical/architecture.md#dashboard): the USGS credit and disclaimer, the map
  credits, the third-party licenses, the privacy notice (`/privacy`: no cookies, storage, tracking or location; the
  Worker keeps no invocation logs), and the build the page was made from (`git describe`), linked to GitHub. `check`
  shows which build is live.
- The page opens on This week, per hour, all magnitudes, stacked columns, the map at zoom 1 (closest 15); its menus
  count under the other filters, the Tsunami box (Flagged only) included. Under the map, the significant events
  (10, 25 or 50 from Show): a row flies the map to its event at zoom 5 and opens its popup. A popup gives the time to
  the second in UTC and where it happened, as `AKDT (UTC-8)` or, without an abbreviation, `(UTC+9)`, and
  `tsunami flagged` when it is. Above 25,000 filtered events the map shows cells counted in SQL, and the visible
  area's events once zoomed in to 4 (docs/technical/architecture.md#dashboard).

## Report

For `check`: the page's status and time, the snapshot's run, row count and age, and the headers. For the
others: the result, and the address or deployment version.
